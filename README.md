# 🇯🇵 Nihongo by Danz-Sensei

Web game edukasi interaktif untuk belajar bahasa Jepang.

## 🎮 Modul Permainan

| Modul | Deskripsi | Link |
|---|---|---|
| **Ikimasho! — Kana Journey** | Belajar Hiragana & Katakana dalam 30 langkah | [Mainkan](https://username.github.io/nihongo-basic-jcuntan/hirakatamainpage.html) |
| **日本語クイズ — Kosakata** | Kuis 100 kosakata benda dengan emoji | [Mainkan](https://username.github.io/nihongo-basic-jcuntan/goimainpage.html) |
| **Nihongo Talk — Kaiwa** | Visual novel percakapan dasar bersama Aoi-sensei | [Mainkan](https://username.github.io/nihongo-basic-jcuntan/kaiwamainpage.html) |

## 🚀 Teknologi
- HTML5 + CSS3 + Vanilla JavaScript
- Three.js (WebGL) untuk background animasi
- LocalStorage JSON untuk penyimpanan skor
